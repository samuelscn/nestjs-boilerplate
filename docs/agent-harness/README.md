# Agent harness

`AGENTS.md` é o índice curto. Esta pasta mantém instruções estáveis e
versionadas para que agentes trabalhem com o mesmo contexto que os humanos.

Quando um erro se repetir, corrija o código e transforme a regra em documentação,
teste ou validação automática. Não dependa de histórico de conversa.

Fontes principais:

- `task-routing.md`: o que ler por tipo de tarefa.
- `verification.md`: como escolher verificações.
- `../CODING-PATTERNS.md`: limites entre camadas.
- `../integration-patterns.md`: APIs externas e observabilidade.
